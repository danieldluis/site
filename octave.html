Lógica de Programação com Octave

▶️

printf

O printf no GNU Octave é uma função de saída formatada, modelada à função homónima da linguagem C, que imprime argumentos opcionais para o stdout sob o controlo de uma template string e devolve o número de caracteres escritos; os especificadores de conversão introduzidos por % (como %d/%i para inteiros, %f para ponto flutuante, %e para notação científica, %s para strings, %c para caracteres e %% para o símbolo literal) substituem-se pelos argumentos seguintes, permitindo controlar largura e precisão do campo (ex.: %9.3f), e, ao contrário do printf do C, quando se passa um vetor ou matriz como argumento, a template é reaplicada a cada elemento em ordem por colunas, o que torna a função particularmente conveniente para imprimir matrizes inteiras de uma só vez. A função disp imprime o valor tal como está, no formato definido por format, sem controlo sobre o layout; printf imprime segundo um template com especificadores (%d, %f, %s, etc.), permitindo controlar largura, precisão e separação de cada elemento, e devolve o número de caracteres escritos.

input

A função input no Octave é uma função built-in de entrada interativa que imprime um prompt e aguarda o utilizador; na forma ans = input(prompt), a cadeia introduzida é avaliada como uma expressão — podendo ser uma constante literal, o nome de uma variável, ou qualquer código Octave válido — pelo que o valor, a dimensão e a classe do resultado dependem do que o utilizador escrever (ex.: input("n = ") com entrada 2^10 devolve 1024); na forma ans = input(prompt, "s"), a cadeia é devolvida literalmente como string, sem avaliação, o que é útil para obter nomes de ficheiros, expressões simbólicas ou texto livre; no prompt estão disponíveis as funções normais de edição e histórico de linha de comandos, e é boa prática chamar fflush(stdout) antes de input para garantir que toda a saída pendente no pager é escrita no ecrã antes do prompt aparecer.

Variáveis e Tipos de Dados

No Octave, as variáveis são dinamicamente tipadas — não é preciso declarar o tipo, que é inferido na atribuição — e podem mudar de tipo ao longo do programa (ex.: x = 5 seguido de x = "olá"); o nome deve começar por letra, pode conter letras, dígitos e _, e não deve começar por dígito; a variável especial ans guarda sempre o último resultado não atribuído. Os tipos de dados built-in são: numéricos reais (double por omissão, single), inteiros (int8/16/32/64, uint8/16/32/64), lógicos (logical, valores true/false), caracteres (char, cadeias de texto), complexos (double complex, single complex), estruturas (struct, campos nomeados) e arrays de células (cell, que podem conter elementos de tipos heterogéneos); o tipo de uma variável é consultado com class, typeinfo ou isa, e convertido com cast (ex.: cast(x, "uint8")) ou reinterpretado a nível de bits com typecast; além disso, o Octave suporta user-defined classes para estender o conjunto de tipos com tipos personalizados.

Condições IF

No Octave, a condição de um if é considerada verdadeira se o seu valor for diferente de zero e falsa se for zero; se a expressão for um vetor ou matriz, é verdadeira apenas se for não-vazia e todos os elementos forem não-nulos (equivalente a all(matrix(:))); os operadores relacionais (==, ~=, <, >, <=, >=) devolvem valores lógicos, e os operadores lógicos && (e), || (ou) e ~ (não) permitem combinar condições, com short-circuit evaluation nos operadores && e ||; a sintaxe usa if…elseif…else…endif, sendo importante que elseif seja escrito como uma única palavra — se escrever else if (com espaço), o Octave interpreta-o como um if aninhado dentro da cláusula else, o que muda completamente o comportamento do código.

▶️

Ciclo While

No Octave, o ciclo while executa repetidamente um bloco de código enquanto uma condição for verdadeira; a condição é avaliada antes de cada iteração (se for falsa desde o início, o corpo nunca executa), e é considerada verdadeira se o seu valor for diferente de zero — se for um vetor ou matriz, é verdadeira apenas se todos os elementos forem não-nulos; a sintaxe é while (condição) ... endwhile, e o corpo pode ser interrompido prematuramente com break (salta para a instrução seguinte ao endwhile) ou reiniciado com continue (salta para o fim do corpo e volta a testar a condição); um caso especial útil é while true (ou while 1), que cria um ciclo infinito controlado exclusivamente por um break interno.

▶️

Ciclo For

No Octave, o ciclo for itera sobre os elementos de uma expressão — tipicamente um range (ex.: 1:n), um vetor, uma matriz ou um cell array — atribuindo a cada iteração o próximo elemento (coluna) à variável de controlo e executando o corpo até esgotar a coleção; a sintaxe é for var = expressão ... endfor, e, ao contrário de uma atribuição normal, a expressão é percorrida coluna a coluna (pelo que for i = [1,3;2,4] produz dois vetores colunas [1;2] e [3;4]); o corpo pode ser interrompido com break (salta para a instrução seguinte ao endfor) ou reiniciado com continue (passa para o próximo elemento); existe também uma forma especial for [val, key] = estrutura que percorre os campos de uma struct devolvendo o nome e o valor de cada um; embora seja possível reescrever qualquer for como while, o for é preferível quando o número de iterações é conhecido a priori, pois é mais natural e menos propenso a erros de off-by-one. O vídeo demonstra of ciclo for com a forma de três argumentos do operador : — início:passo:fim — oferecendo mais controlo ao utilizador e gera o vetor [0, 20, 40, 60, 80, 100] (100 é exatamente atingido, pelo que está incluído); portanto for i = 0:20:100 ... endfor itera 6 vezes, com i assumindo sucessivamente 0, 20, 40, 60, 80 e 100.

Editor de Scripts

O Editor de Scripts no GNU Octave é uma ferramenta integrada à interface gráfica (GUI) que facilita a criação, edição e execução sequencial de comandos. Pode-se aceder na aba Script Editor ou pelo menu File >> New Script e também pode ser aberto via linha de comandos digitando edit "nome_do_ficheiro".

Estrutura de uma Função em Octave

Uma função no Octave é um bloco de código nomeado que recebe argumentos de entrada, executa uma tarefa específica e (opcionalmente) retorna valores de saída, delimitado por function ... endfunction (ou end). Diferente de um script, o escopo das variáveis internas é local — nada sai para o workspace — e a função pode ser chamada quantas vezes se quiser pelo nome da mesma. É a unidade básica de reutilização de código no Octave, análoga às funções do MATLAB.
