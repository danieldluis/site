A função print() é uma função embutida no Python 3 que permite exibir mensagens, valores de variáveis e resultados de cálculos no console durante a execução de um programa.

A função print() é uma das primeiras ferramentas que os iniciantes aprendem, servindo como uma ponte para ver o código funcionando em tempo real.

Para imprimir múltiplos itens na mesma linha, separe-os por vírgula, como em print("Olá", "Mundo"), que resultará em Olá Mundo.

Diferente de return, que envia um valor para ser usado no código, print apenas mostra a informação ao utilizador final.

A função input() é uma função embutida no Python 3 que permite solicitar e receber dados digitados pelo utilizador durante a execução do programa, pausando o código até que a tecla "Enter" seja pressionada. Permite Retorno de Texto independentemente do que o utilizador digite (números, letras ou símbolos), a função input() retorna sempre o dado como uma string (texto). Se você precisar fazer cálculos matemáticos com esse valor, deverá convertê-lo primeiro, usando funções como int() ou float(). Mensagem de Prompt: Você pode incluir uma mensagem de texto dentro dos parênteses, como input("Nome: "), para orientar o utilizador sobre o que deve ser inserido. Essa mensagem aparece no console antes da espera pela digitação. Armazenamento: O valor digitado geralmente é atribuído a uma variável para ser utilizado posteriormente no código, por exemplo: nome = input("Nome? "). Diferença do print: Enquanto print() exibe informações na tela (saída), input() captura informações do teclado (entrada), tornando os programas interativos.
