print()

A função print() é uma função embutida no Python 3 que permite exibir mensagens, valores de variáveis e resultados de cálculos no console durante a execução de um programa.

A função print() é uma das primeiras ferramentas que os iniciantes aprendem, servindo como uma ponte para ver o código funcionando em tempo real.

Para imprimir múltiplos itens na mesma linha, separe-os por vírgula, como em print("Olá", "Mundo"), que resultará em Olá Mundo.

Diferente de return, que envia um valor para ser usado no código, print apenas mostra a informação ao utilizador final.

▶️

input()

A função input() é uma função embutida no Python 3 que permite solicitar e receber dados digitados pelo utilizador durante a execução do programa, pausando o código até que a tecla "Enter" seja pressionada. Permite Retorno de Texto independentemente do que o utilizador digite (números, letras ou símbolos), a função input() retorna sempre o dado como uma string (texto). Se precisar de fazer cálculos aritméticos com esse valor, deverá convertê-lo primeiro, usando funções como int() ou float(). Mensagem de Prompt em que se pode incluir uma mensagem de texto dentro dos parênteses, como input("Nome: "), para orientar o utilizador sobre o que deve ser inserido. Essa mensagem aparece no console antes da espera pela digitação. O valor digitado geralmente é atribuído a uma variável para ser utilizado posteriormente no código, por exemplo: nome = input("Nome? ").

Enquanto print() exibe informações na tela (saída), input() captura informações do teclado (entrada), tornando os programas interativos.

Variáveis e Tipos de Dados

As variáveis em Python funcionam como referências a objetos na memória, sendo criadas automaticamente ao receberem um valor (tipagem dinâmica). Não é necessário declarar o tipo explicitamente; o interpretador inferi o tipo com base no valor atribuído, permitindo que uma variável armazene diferentes tipos de dados ao longo da execução. Os principais tipos de dados incluem:

  • Numéricos: int (inteiros), float (ponto flutuante/decimal) e complex (números complexos).

  • Sequências: str (strings/texto), list (listas mutáveis), tuple (tuplas imutáveis) e range.

  • Mapeamento: dict (dicionários com pares chave-valor).

  • Outros: bool (booleanos: True/False), set/frozenset (conjuntos) e NoneType (valor nulo).

A conversão de tipos (casting) é realizada através de funções específicas como int(), float(), str() e bool(). O Python realiza conversões implícitas automáticas em operações mistas (ex: soma de int com float resulta em float), mas conversões explícitas são necessárias para operações incompatíveis, como transformar entrada de texto em número para cálculos matemáticos.

Condições IF

As estruturas condicionais em Python, como if, elif e else, controlam o fluxo do programa executando blocos de código apenas quando certas condições são avaliadas como verdadeiras. O comando if testa a condição principal; se for falsa, o programa verifica blocos elif (abreviação de "else if") para condições alternativas, e executa o bloco else se nenhuma das anteriores for atendida. A indentação é obrigatória para definir quais linhas pertencem a cada bloco condicional. Conceitos Importantes:

  • Operadores: Use == para comparação (retorna True/False) e = para atribuição.

  • Valores Falsy: O Python trata valores como 0, None, "", [] e False como falsos em condições.

  • Ternário: Para decisões simples em uma linha, use valor_se_verdadeiro if condição else valor_se_falso.

  • Aninhamento: É possível colocar estruturas if dentro de outras, mas o excesso deve ser evitado para manter a legibilidade.

    • Essas estruturas são fundamentais para tomar decisões dinâmicas no código, permitindo que o programa reaja diferentemente conforme os dados ou entradas do utilizador.

Ciclo While

O comando while em Python executa um bloco de código repetidamente enquanto uma condição específica for avaliada como verdadeira (True). Diferente do for, que itera sobre uma sequência definida, o while é ideal para situações onde o número de repetições é desconhecido ou depende de uma condição dinâmica. A estrutura verifica a condição antes de cada iteração. Se a condição for falsa inicialmente, o bloco de código nunca será executado. A indentação é obrigatória para definir o escopo do loop.

Uma característica única do Python é a possibilidade de usar um bloco else após o while. Este bloco é executado apenas se o loop terminar naturalmente (quando a condição se torna falsa). Se o loop for interrompido prematuramente por um comando break, o bloco else é ignorado.

Para gerenciar a execução do loop, utilizam-se comandos específicos como o break que encerra o loop imediatamente, transferindo o controle para a primeira linha após o bloco e continue, o qual interrompe a iteração atual e retorna ao início do loop para reavaliar a condição, pulando o código restante naquela volta.

▶️

Ciclo For

O comando for em Python é utilizado para iterar sobre uma sequência (como listas, tuplas, dicionários, conjuntos ou strings) ou qualquer outro objeto iterável. Diferente do while, que depende de uma condição booleana, o for executa o bloco de código uma vez para cada item na sequência, tornando-o mais conciso e seguro contra loops infinitos acidentais quando se trabalha com coleções de dados.

A função range(início, fim, passo) é o que mais se aproxima do for tradicional pois permite controlar o índice e o número exato de repetições:

  • inicio: Opcional, padrão é 0.

  • fim: Obrigatório (o loop para antes de atingir este valor).

  • passo: Opcional, padrão é 1. Define o incremento.
