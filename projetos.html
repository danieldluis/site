Projeto - Logo Interativo com Python!

A biblioteca Turtle em Python permite criar imagens, formas e animações fornecendo uma tela de pintura virtual onde uma "tartaruga" (cursor ou caneta) se move para desenhar linhas e padrões. Originalmente baseada na linguagem Logo, esta biblioteca gráfica pré-instalada é comumente utilizada para ensinar conceitos de programação (como loops, funções e variáveis) de forma visual e interativa.

Projeto - Conversor de Mp4 em GIF com Python!

A biblioteca MoviePy em Python permite converter vídeos, áudios e imagens entre os principais formatos suportados, como MP4, WebM, GIF, AVI, MOV e outros. Ela usa o FFmpeg (projeto de software gratuito e open-source com um conjunto de bibliotecas e ferramentas de linha de comandos para processar praticamente qualquer ficheiro ou stream de vídeo, áudio e multimédia) no background para fazer o codificação e decodificação, o que dá suporte a praticamente todos os formatos de vídeo e áudio comuns.
